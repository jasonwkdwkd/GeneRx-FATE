# Data sources and evidence status

The expansion runs entirely on synthetic parameters. The following sources document mechanisms, reproduce earlier analyses, or identify candidate calibration datasets. Their inclusion here does not imply that the expansion was fit or tested on them.

| Source and citation | Quantity or role | Status and reproducibility |
|---|---|---|
| [Norman et al., Science (2019), doi:10.1126/science.aax4438](https://doi.org/10.1126/science.aax4438) · [GEO GSE133344](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE133344) | K562 CRISPRa control, single and paired expression profiles | Published [GeneRx-FATE reconstruction and prediction workflow](../../README.md). Source filenames and commands are given there. See [pooled scores](../../benchmark.json) and [audit records](../../evidence/). |
| [Wessels et al., Nature Methods (2023), PMID 36550277](https://pubmed.ncbi.nlm.nih.gov/36550277/) · [GEO GSE213957](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE213957) | THP-1 CaRPool-seq control, single and double knockdowns | Separate GeneRx-FATE replication, with within-THP-1 retraining; it does not calibrate CDIE. The separate replication used the THP-1 metadata and the GEXGDO matrices in the THP-1/HEK293FT archive from GEO. This directory documents data provenance; the THP-1 replication scripts and scores are maintained separately. |
| [GEO GSE104714](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE104714), Vockley, McDowell and colleagues | A549 dexamethasone versus vehicle expression time courses | Earlier standalone [RNA projection](../rna_benchmark.py). [Recorded scores and exact input SHA-256](../A549_results.json). The exploratory blend is distinct from a prespecified external test. |
| [MaveDB BRCA1 gene catalogue](https://www.mavedb.org/genes/BRCA1), score sets [00001222-b-2](https://api.mavedb.org/api/v1/score-sets/urn:mavedb:00001222-b-2) and [00001222-a-2](https://api.mavedb.org/api/v1/score-sets/urn:mavedb:00001222-a-2) | Homology-directed repair and cisplatin-resistance assay scores | Earlier standalone [assay-to-assay benchmark](../brca1_benchmark.py) with residue-block holdout. Repair scores are available at test time. [Recorded scores, matching scope and input SHA-256](../BRCA1_results.json). |
| [Petryk et al., Nature Communications (2016), doi:10.1038/ncomms10208](https://doi.org/10.1038/ncomms10208) and [Holt and Reyes, doi:10.1101/cshperspect.a012971](https://doi.org/10.1101/cshperspect.a012971) | Nuclear initiation zones and mtDNA replication mechanisms | Basis for separating scheduled nuclear origin zones from the illustrative mitochondrial strand-displacement model. The code uses synthetic origin coordinates, rates and delays. |
| [Hillen et al., Cell (2017), doi:10.1016/j.cell.2017.10.036](https://doi.org/10.1016/j.cell.2017.10.036) · [Ojala et al., Nature (1981), doi:10.1038/290470a0](https://doi.org/10.1038/290470a0) | Mitochondrial transcription initiation and tRNA punctuation | Mechanistic references. No kinetic constants were inferred from these papers. |
| [Aryaman et al., Biochemical Journal (2017), PMCID PMC5705840](https://pmc.ncbi.nlm.nih.gov/articles/PMC5705840/) · [Mitochondrial tRNA study, Nature Communications (2024), doi:10.1038/s41467-024-53318-x](https://doi.org/10.1038/s41467-024-53318-x) | Candidate measurements for heteroplasmy, tRNA abundance/function and respiration | Proposed calibration/validation sources. Obtain the published data and units, record assay and clone identities, and prespecify training and testing before use. |
| [Abou Tayoun et al., PMID 30192042](https://pubmed.ncbi.nlm.nih.gov/30192042/) · [Sosnay et al., doi:10.1038/ng.2745](https://doi.org/10.1038/ng.2745) | Premature termination interpretation and CFTR allele function | Mechanistic and benchmark-design references. CFTR examples in the code use synthetic changes and have no fitted variant effect. |

For any future run, save the accession or immutable dataset version, accession-specific filenames and SHA-256 hashes, preprocessing code, split assignments, exclusions, parameter estimates and intervals, software versions, and scored outputs. Cite the source study and repository accession. The expansion package contains no redistributed patient-level records.
